# LibroLink — Refined Flutter Client Prototype

A polished Flutter UI prototype for the LibroLink library mobile application.

## Included

- Refined blue/cyan visual system
- Poppins typography via `google_fonts`
- Single hamburger menu in the upper-left app bar
- Dedicated Profile page with avatar and student/account details
- Dedicated About page
- Dedicated Help Center page
- Seat reservation flow
- Digital library and search
- Bookmarks
- Reader view with text-size and reading-theme controls
- Light/dark mode
- Responsive cards, buttons, form fields, empty states, and navigation
- Subtle library-inspired gradient background without requiring a large image asset

## Run

```bash

```
